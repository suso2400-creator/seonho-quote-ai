# 선호테크 견적서 AI

프레스 가공품(프로그레시브 · 단발 · 트랜스퍼) 견적서를 만드는 단일 HTML 웹앱입니다.
설치나 서버 없이 `index.html` 하나로 동작하며, 입력한 데이터는 사용하는 브라우저에 저장됩니다.

## 사용

- GitHub Pages: 저장소의 Pages 주소로 접속
- 오프라인: `index.html`을 내려받아 더블클릭

## 주요 기능

- 품목별 원가 자동 계산: 재질·두께·소재 폭·이송 피치·취수 → 블랭크 중량 → 재료비(스크랩 회수 차감), 공정별 가공비(프레스 임률 ÷ 60 ÷ SPM ÷ 취수 ÷ 가동률 + 셋업비 ÷ 수량), 후공정 6종·포장·부자재, 불량률·관리비율·이윤율 → 단가
- 프레스 5대 임률 관리, 전단 길이로 필요 톤수 계산 → 적합 여부·권장 호기 표시, SPM 초과 경고
- 소재 조달(자사 구매 / 고객 사급), 금형비 처리 3방식: 해당 없음 / 별도 청구(견적서에 행 추가) / 단가 상각
- A4 표준 견적서 미리보기 · 인쇄(PDF), 한글 금액 표기, 원가 내역서(내부용) 출력
- 견적 목록(작성중·발송·수주·실주), 복제, CSV 내보내기, JSON 백업 · 복원
- 기준 정보(회사 정보, 프레스 설비, 소재 단가표, 원가 계수, 견적 조건 기본값) 편집

## 데이터

브라우저의 로컬 저장소에만 보관됩니다. 다른 PC로 옮기거나 보관하려면 견적 목록 화면의 **전체 백업(JSON)**을 사용하세요.
기본 프레스 임률과 소재 단가는 예시 값이므로 자사 기준으로 수정해 사용하세요.
